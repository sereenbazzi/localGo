# LocalGo User Stories

## DMC

### US-001 — Create Experience
As a DMC,
I want to create an experience listing,
so that travel agencies can discover and book my services.

### US-002 — Manage Experiences
As a DMC,
I want to manage my experience listings,
so that their information remains accurate.

### US-003 — Manage Availability
As a DMC,
I want to manage the availability of my experiences,
so that agencies know when they can be booked.

### US-004 — Manage Bookings
As a DMC,
I want to view and manage bookings related to my experiences,
so that I can handle Agency requests.


## Agency

### US-005 — Search Experiences
As an Agency,
I want to search and filter experiences,
so that I can find suitable services for my clients.

### US-006 — Check Availability
As an Agency,
I want to check or request availability,
so that I know whether an experience is suitable for my clients' dates.

### US-007 — Create Booking
As an Agency,
I want to book an experience,
so that I can reserve the service for my clients.

### US-008 — Track Bookings
As an Agency,
I want to view my bookings and their statuses,
so that I can track my reservations.

### US-009 — Review Experience
As an eligible Agency,
I want to review an experience,
so that I can provide feedback.


## Admin

### US-010 — Moderate Marketplace
As an Admin,
I want to moderate marketplace content,
so that LocalGo content follows the platform rules.


## AI Trip Planner

### US-011 — Generate Trip Plan
As an Agency,
I want the AI Trip Planner to create a multi-day itinerary,
so that I can quickly prepare a trip for my clients.

### US-012 — Generate Relevant Trip Plan
As an Agency,
I want the AI Trip Planner to consider dates, budget, group requirements,
and availability,
so that the generated itinerary is suitable for my clients.
