# LocalGo 

LocalGo is a web-based travel marketplace that connects **Travel Agencies** with **Destination Management Companies (DMCs)**.

The platform allows DMCs to offer travel services such as tours, activities, transportation, and guides, while travel agencies can explore available services, request availability, and make bookings.

### Main Features
- **DMCs:** Create and manage travel services and bookings.
- **Travel Agencies:** Search for services, check availability, and make reservations.
- **Admins:** Manage users, listings, and platform activities.
- **AI Trip Planner (Planned):** Help create personalized travel itineraries based on customer preferences and available services.

### Technologies
- **Frontend:** React (planned)
- **Backend:** Node.js, Express.js, TypeScript
- **Database:** PostgreSQL
